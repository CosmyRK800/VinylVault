# VinylVault

E-commerce music store for vinyl records, CDs and cassettes.

Built with React, Zustand, TailwindCSS and Supabase.

## Stack
- React + Vite
- Zustand (state management)
- TailwindCSS
- Supabase (database)
- EmailJS (contact form)

## Run locally
1. Clone the repo
2. `cd frontend && npm install`
3. Create `.env` from `.env.example` and add your Supabase keys
4. `npm run dev`
